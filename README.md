# Выдающиеся лингвисты Казахстана

Презентация о Ахмете Байтурсынове и Кудайбергене Жубанове.

## Как открыть

Откройте `index.html` в браузере. Управление: `→` или пробел — следующий слайд.

## GitHub Pages

1. Загрузите файлы в репозиторий.
2. Settings → Pages → Branch: `main`, папка `/ (root)`.
3. Сайт появится по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.
